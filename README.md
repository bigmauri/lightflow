## 🚀 Introduction

**Lightflow** is a lightweight, and distributed workflow system designed to orchestrate a sequence of tasks in a declarative way. Built on **Python 3+**, Lightflow is an excellent solution for managing long-running processes, especially in automation procedure.

---

## ✨ Key Features

* **Declarative Workflows:** Define entire workflows and task dependencies building in a YAML file, eliminating the need to learn proprietary configuration languages.
* **Sequence Based Execution:** Workflows are modeled giving you precise control over task ordering and parallel execution. 
* **Reusable Task Types:** Easily integrate custom logic in your custom sequence yaml file.

---

### Prerequisites

Lightflow requires the following services to be running:

1.  **Python 3+**
2.  **Protobu** Used to build the sequence structure definition.
